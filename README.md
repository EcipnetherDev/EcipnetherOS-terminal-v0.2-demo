# EcipnetherOS Terminal v0.2 — Demo

> Hello, friend.

A Windows kernel terminal application.  
*Bu, bir Windows çekirdek terminal uygulamasıdır.*

## Important note

This program was built with PyInstaller. Some antivirus programs may falsely flag single-file Python executables as suspicious.

*Program PyInstaller ile oluşturulmuştur. Bazı antivirüs programları tek dosyalı Python EXE’lerini yanlış pozitif olarak şüpheli gösterebilir.*

## Download and setup

Download the ZIP file, extract it, and run `TerminalOS.exe`.  
Keep the `.json` files and folders in the same directory as the EXE file.

*ZIP dosyasını indirip ayıklayın ve `TerminalOS.exe` dosyasını çalıştırın. JSON dosyaları ve klasörler EXE ile aynı dizinde kalmalıdır.*
